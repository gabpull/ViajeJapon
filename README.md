# Incluido

Página para ver **películas y series incluidas** en Apple TV+ y Claro Video, sin alquilar ni pagar de más.

## Desarrollo

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Notas

- Apple TV+: se listan Apple Originals (incluidos en la suscripción).
- Claro Video: catálogo / Universal+ / Atresplayer típico incluido; **no** incluye alquiler ni PPV. La disponibilidad cambia por país y plan.
